# Fairlead feedback

Help the person send feedback on this Fairlead tester release. Never include their topic, their prompts, their results or any file contents: only what is listed below.

1. Gather these, and show them to the person as a short block they can copy:
   - **Plugin version:** 0.1.1
   - **Braid:** fairlead.lit_scoping_review@0.4.0
   - **Claude Code version:** run `claude --version` in a shell if you can; otherwise ask the person.
   - **Operating system:** Windows, macOS or Linux.
   - **Run id and practice headline,** if this conversation ran a Fairlead braid: the run id (it starts with `run_`) and the "Practice:" line `fairlead_deliver` returned. If the run did not finish, say which step it reached and what went wrong, in a sentence, without quoting any content.
2. Give them the feedback form: (the link is on its way: your tester invitation will have it)
3. Suggest what is most useful to the Fairlead team: what worked, what did not, anything that was confusing, how long it took, and whether they would use the result.
